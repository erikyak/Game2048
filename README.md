# Лабораторная работа 3 – Unit-тестирование

Данный проект представляет собой реализацию набора unit-тестов для кодовой базы, разработанной в рамках лабораторных работ 1 и 2. Основная цель работы – повысить надёжность и качество кода посредством автоматизированного тестирования, а также обеспечить достижение требуемых метрик line-coverage с помощью установленного пакета Code Coverage.

## Цели и задачи

- **Покрытие тестами функционала:**  
  Разработаны тесты для основных компонентов игры, включая:
  - **GameField:** Проверка создания, удаления, обновления позиций клеток и корректного возврата пустых позиций.
  - **Cell:** Тестирование методов изменения значения и позиции, а также вызова соответствующих событий.
  - **PlusScore:** Валидация отображения и анимации UI-элементов для начисления дополнительных очков.
  - **CellData:** Проверка корректной инициализации структуры данных, хранящей позицию и значение клетки.
  - **GameManager:** Тесты для проверки логики слияния клеток, подсчёта очков, сохранения и восстановления игрового состояния, а также корректного завершения игры.
  - **GameFieldGizmos:** Тестирование визуальной отладки (отрисовки Gizmos) для игрового поля.
  - **MonoBehaviour:** Интеграционные тесты для проверки взаимодействия различных компонентов (например, InputHandler, CellView) в игровом цикле.

- **Использование Fluent Assertions:**  
  Все тесты реализованы с помощью библиотеки Fluent Assertions.

## Запуск тестов и получение отчёта по покрытию

1. **Запуск тестов:**  
   - Откройте окно Test Runner в Unity и запустите все тесты.
   - Тесты проверяют корректность работы основных компонентов и сценариев игры.

2. **Получение отчёта по покрытию:**  
   - Установите пакет Code Coverage через Package Manager.
   - Запустите сбор покрытия кода через окно Code Coverage.

## Выводы

- **Надёжность:**  
  Набор тестов позволяет оперативно выявлять ошибки и регрессии в кодовой базе, что значительно повышает надёжность и стабильность игрового приложения.

- **Поддерживаемость:**  
  Автоматизированное тестирование упрощает дальнейшую разработку и модификацию проекта, гарантируя, что изменения не нарушат существующий функционал.

- **Качество кода:**  
  Достижение высоких показателей line-coverage подтверждает, что тестами покрыт значительный объём логики, что является показателем высокого качества реализации.
