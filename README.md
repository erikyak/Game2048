## Описание проекта
В рамках первой лабораторной работы был разработан прототип игры 2048 на Unity. Цель работы заключалась в создании заготовки, включающей:
- Вёрстку игрового поля.
- Логику инициализации игры.
- Реализацию базовых классов для управления игровыми клетками.

## Структура проекта

### Cell.cs
- **Описание:** Класс `Cell` представляет игровую клетку, хранящую её позицию и текущее значение.
- **События:**  
  - `OnValueChanged` – вызывается при изменении значения клетки.
  - `OnPositionChanged` – вызывается при изменении позиции клетки.

### GameField.cs
- **Описание:** Компонент `GameField` управляет игровым полем и списком клеток.
- **Методы:**
  - `Start` - каждую секунду вызывает `CreateCell`, который создает новую клетку(Просто для показ того, что код работает)
  - `GetEmptyPosition` – возвращает случайную пустую позицию на поле.
  - `CreateCell` – создаёт новую клетку в случайной пустой позиции:
    - С вероятностью 90% значение клетки равно 2.
    - С вероятностью 10% значение клетки равно 4.
    - При создании клетки происходит инстанцирование префаба с компонентом `CellView` и его инициализация.

### CellView.cs
- **Описание:** Компонент `CellView` отвечает за визуальное отображение клетки.
- **Методы:**
  - `Init` – инициализирует отображение клетки, подписываясь на события `OnValueChanged` и `OnPositionChanged` объекта `Cell`.
  - `UpdateValue` – обновляет текстовое значение префаба.
  - `UpdatePosition` – обновляет позицию префаба на экране согласно координатам клетки.
 
### CellNumber.cs
- **Описание:** Компонент `CellNumber` хранит инфомацию о типе клетке: ее значение и цвет.
- **Примечание:** В `CellNumber` существует рудиментарный `fontSize`, который будет убран в следующей лабораторной работе

### CellNumberLoader.cs
- **Описание:** Компонент `CellNumberLoader` отвечает за загрузку всех `CellNumber` в список, для дальнейшего использования.
- **Методы:**
  - `Awake` – берет все `CellNumber` в папке `Resources` и добавляет в статический список `cellNumbers`
