# Игра 2048 

Данный проект представляет собой реализацию игры 2048. В этой версии добавлена полноценная логика игрового процесса, система подсчёта очков, реализация слияния клеток, а также механизмы сохранения и восстановления прогресса. Ниже приведено описание основных аспектов работы.


## Основной функционал

### Пользовательский ввод
- **Поддерживаемые методы ввода:**  
  - Клавиатура (WASD и стрелки).
  - Свайп мышью.
  - Свайп по сенсорному экрану.
- **Логирование:** Все действия ввода логируются в консоль Unity, что позволяет отслеживать действия игрока в режиме реального времени.

### Динамическое обновление игрового поля
- **Добавление новых клеток:**  
  После каждого хода создаётся новая клетка:
  - С вероятностью 20% новая клетка получает значение 4.
  - В остальных случаях создаётся клетка со значением 2.
  
- **Визуальное представление:**  
  Каждая клетка меняет свой цвет при увеличении значения. Для этого используется ScriptableObjectы с разными цветами текста и ячейки для каждого значения клетки.

### Механика движения и слияния клеток
- **Движение клеток:**  
  Клетки перемещаются в выбранном направлении. Логика движения организована таким образом, что клетки перемещаются последовательно, учитывая порядок сдвига (отрицательные и положительные направления обрабатываются отдельно).
  
- **Слияние клеток:**  
  При столкновении клеток с одинаковыми значениями происходит их объединение, в результате чего значение удваивается. Этот процесс также влияет на подсчёт очков.

### Система подсчёта очков
- **Подсчёт:**  
  Очки обновляются после каждого изменения значений на клетках.
- **Отображение:**  
  Текущий счёт и рекорд (лучший результат) отображаются на экране. При каждом изменении результатов данные также сохраняются.

### Сохранение и восстановление прогресса
- **Сохранение:**  
  Прогресс игры сохраняется в двух бинарных файлах. В первом файле записываются положения и значения всех клеток, а также текущий счёт. Во втором - лучший счет.
- **Восстановление:**  
  При запуске приложения проверяется наличие файла сохранения. Если он найден, данные восстанавливаются, позволяя игроку продолжить игру с того места, на котором он остановился.
- **Ограничения:**  
  Для сохранения данных не используется PlayerPrefs.

### Логика завершения игры и рестарта
- **Проверка состояния:**  
  Игра завершается, если после хода не остаётся свободных позиций и отсутствуют возможные варианты для слияния клеток.
- **Обработка проигрыша:**  
  При достижении состояния «игра окончена»:
  - Выводится соответствующее сообщение.
  - Отключается ввод пользователя.
- **Рестарт:**  
  Реализована возможность сброса текущей игровой сессии с последующим началом новой игры.

## Запуск проекта
1. **Открытие проекта:**  
   Откройте проект в Unity.
2. **Запуск игры:**
   3.1. Откройте сцену SampleScene в папке Assets/Scenes.
   3.2. Нажмите кнопку Play.

## Заключение
В данной работе реализована полноценная игровая логика для 2048, которая включает:
- Обработку различных способов ввода,
- Динамическое обновление игрового поля с генерацией новых клеток,
- Механизмы движения и слияния клеток с визуальными эффектами,
- Систему подсчёта очков и сохранения прогресса,
- Логику завершения игры и возможности рестарта игровой сессии.
